# Dockerized Flask Python App

A simple Flask web application deployed on a Google Cloud Virtual Machine and exposed to the internet using ngrok.

## Features

- Flask Web Application
- Visitor Counter (SQLite)
- Search Visitors
- Docker Ready
- Responsive UI
- Google Cloud Platform
- ngrok Public Access

## Technologies Used

- Python 3
- Flask
- SQLite
- Docker
- Debian 13
- Google Cloud Platform
- Git & GitHub

## Project Structure

```text
my-python-app/
├── app.py
├── Dockerfile
├── requirements.txt
├── templates/
├── static/
└── README.md
```

## Run Locally

```bash
pip install -r requirements.txt
python3 app.py
```

Open:

```
http://localhost:5000
```
